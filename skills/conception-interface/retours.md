# Retours d'expérience

Une entrée par projet réel, ajoutée à la fin du projet. Ne modifier une règle du skill
que lorsque plusieurs entrées convergent.

Les retours bruts vont dans `retours-prives.md` (même modèle, non publié : exclu par
`.gitignore`). Ce fichier-ci, publié, ne reçoit que des retours anonymisés.

Modèle :

## AAAA-MM-JJ · <projet> · <type d'interface>
- **Avant/après** : (chiffres clés)
- **A servi** :
- **A manqué ou gêné** :
- **Nouveaux pièges** :
- **Essai témoin** : non fait | A/B choisi : …, révélé : …
